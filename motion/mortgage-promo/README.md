## Пересборка

Из корня репозитория:

```sh
source .venv/bin/activate
export PLAYWRIGHT_BROWSERS_PATH="$PWD/.playwright-browsers"
python -m http.server 8765 --bind 127.0.0.1
```

Превью: `http://127.0.0.1:8765/motion/mortgage-promo/video.html?preview=1&subs=0`.

В другом терминале, в том же окружении (при разрешённом запуске Chromium):

```sh
python motion/mortgage-promo/render.py --url 'http://127.0.0.1:8765/motion/mortgage-promo/video.html?fmt=h&subs=0'
python .agents/skills/product-motion/scripts/verify_media.py motion/mortgage-promo/plan.js motion/mortgage-promo/out/mortgage-promo_16x9.mp4 --sheet
```

Или пересобрать MP4 из уже снятых `build/frames/*.jpg` без браузера:

```sh
python motion/mortgage-promo/render.py
```

Страницу нужно открывать через сервер корня репозитория: ей требуются исходные HTML и CSS прототипа. Кадры и MP4 исключены из Git; исходники, сценарий и контактный лист остаются в ветке `mortgage-promo`. Перекодирование другим браузером может немного изменить размер файла.
